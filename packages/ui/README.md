# @brownsync/ui

Single responsibility: the BrownSync design system — token CSS, re-themed primitives on Radix,
the 10 hand-drawn category icon glyphs (DOM sprite + MapLibre `addImage` variants), and the
`/dev/ui` gallery components. Design law: handoff §6. No lucide defaults, no gradients,
radius ≤ 6px, one accent color.
